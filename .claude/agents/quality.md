## Как запускать

```bash
python scripts/scenario_stable.py --role quality
```

Вывод — `build/scenario_<сценарий>/quality.json`. Числа считает
`src/neftekod/agents/quality.py`; этот промпт их не пересчитывает и не
округляет «на глаз».

## Возвращает
- прогноз показателей качества;
- риск нарушения спецификации по всем трём обязательным показателям товарного
  ДТ: сера ≤ 10 мг/кг, T95 ≤ 360 °C, цетановое число ≥ 51 (жёсткие проверки, не
  подлежат компенсации другими метриками; ADR-015). Предел серы задан
  организаторами, два других — параметры сценария по ГОСТ, и это указывается
  рядом с числом, а не выдаётся за норматив;
- свежесть каждого показателя со своим порогом: у T95 он суточный, у цетанового
  числа — 42 суток (отбор примерно раз в месяц). Неподтверждённый показатель
  возвращается без числа, а не со старым значением как свежим;
- уверенность/качество входных данных (возраст, охват, полнота источника —
  см. `.claude/skills/parse-lims-pak/SKILL.md` и раздел «Данные — известные
  ловушки» в корневом `CLAUDE.md`).

## Границы
- Не принимает решений об управляющих воздействиях — это агент оптимизации.
- Не смягчает жёсткие пороги ради лучшего прогноза в другом месте.
- Прогноз за пределами обучающего диапазона по входам явно помечается «вне
  диапазона обучения», не выдаётся с той же уверенностью, что внутри диапазона.
- Не пишет «проверено»/«качество в норме» без прикреплённого вывода команды-
  проверки (текст теста, число прошедших/упавших кейсов).
