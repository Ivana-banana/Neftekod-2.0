# Нефтекод 2.0

Материалы хакатона: техническое задание, справочные данные и технологические схемы для задачи о мультиагентной системе управления цепочкой АВТ → гидроочистка → блендинг товарного дизельного топлива.

## Структура репозитория

| Файл | Описание |
|---|---|
| `ТЗ_нефтекод.docx` / `ТЗ_нефтекод.md` | Техническое задание для участников (md — версия, удобная для чтения нейросетью). |
| `Теги_хакатон.xlsx` / `Теги_хакатон.md` | Справочник тегов: листы КИП, ЛА, ПАК, ВАК. |
| `АВТ_схемы.pdf` / `АВТ_схемы.md` | Технологические схемы АВТ (md ссылается на изображения страниц в `assets/`). |
| `assets/` | PNG-рендеры страниц `АВТ_схемы.pdf`, используются в `АВТ_схемы.md`. |
| `Выгрузка ПАК 01.01.2023 - н.в_.xlsx` | Данные поточных анализаторов (ПАК). |
| `ЛИМСы 01.01.2023 - н.в_ (2).xlsx` | Лабораторные результаты (ЛИМС). |

## Недостающие файлы (телеметрия)

Два файла с историческими временными рядами телеметрии слишком большие для git (247 МБ и 91 МБ) и **не включены в репозиторий**:

- `data/avt_tags.csv` — телеметрия участка АВТ.
- `data/242000_tags.csv` — телеметрия установки 24-2000 (гидроочистка/стабилизация).

Скачать их можно по ссылке: https://drive.google.com/drive/folders/1nH7mdXxdGIvv8Rp6g170xSrUggMfpN4L?usp=sharing

Описание содержимого и правила синхронизации данных — в `ТЗ_нефтекод.md`, раздел «2. Данные, которые получает команда».
