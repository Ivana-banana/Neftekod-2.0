# ADR-012: baseline прогноза серы — сдвинутый persistence

## Статус

Принято 2026-09-12. Заменяет выбор baseline из ADR-008 (persistence) и
уточняет порог допустимости действия из ADR-010, §3.

## Контекст

Самооценка 2026-09-11 (`docs/self_assessment.md`, §2) нашла подтверждённый
дефект: у persistence отрицательный R² на test (−0.13 при h = 0), то есть он
хуже константы. Константа, равная медиане обучающей выборки, выигрывала
и на valid, и на test — значит, выбор был доступен честно, без подглядывания
в test.

Это не косметика отчёта. Число backtest-RMSE на худшем горизонте служит
порогом допустимости действия (ADR-010, §3): запас по сере должен быть не
меньше одной RMSE. С другим baseline сдвигается граница разрешённых действий,
поэтому baseline фиксируется **до** прогона сценариев, а не после.

## Что проверено на fit/valid до фиксации

Persistence и константа — крайние точки одного семейства:

```
прогноз = shrinkage · последний опубликованный анализ
        + (1 − shrinkage) · уровень обучающей выборки (медиана fit)
```

`shrinkage = 1` — persistence, `shrinkage = 0` — константа. Проверка всей
сетки на valid (test не читался):

| shrinkage | RMSE (h=0) | MAE (h=0) | MedAE (h=0) | MedAE (h=2) |
|---:|---:|---:|---:|---:|
| 0.0 | 8.386 | 2.059 | 1.10 | 1.10 |
| 0.1 | 8.389 | **2.052** | 1.02 | 1.06 |
| 0.2 | 8.399 | 2.066 | 0.98 | 0.98 |
| 0.3 | 8.416 | 2.090 | **0.94** | **0.94** |
| 0.5 | 8.469 | 2.153 | 1.00 | 1.00 |
| 0.7 | 8.548 | 2.247 | 1.04 | 1.03 |
| 1.0 | 8.713 | 2.453 | 1.10 | 1.10 |

Три метрики указывают на разные точки: RMSE — на 0.0–0.2, MAE — на 0.1,
MedAE — на 0.3. Разброс между ними меньше 0.5 %, то есть **на valid эти
варианты статистически неразличимы**. Причина видна отдельно: корреляция
соседних анализов на fit равна −0.004 (на valid −0.027). Лабораторный ряд на
суточном шаге — шум вокруг устойчивого уровня, и «последнее значение» само по
себе почти не предсказывает следующее.

## Решение

1. **Baseline — семейство со сдвигом**, а не выбор «persistence или
   константа». Обе прежние модели входят в сетку и сравниваются числом.
2. **Метрика отбора — MedAE на valid**, тай-брейк — большая `shrinkage`.
   Обоснование метрики: в цели есть выбросы 120 и 2120 мг/кг, из-за которых
   RMSE на valid определяется единичными строками. Обоснование тай-брейка:
   среди неразличимых вариантов система обязана остаться зависимой от свежего
   измерения — прогноз с `shrinkage = 0` не может заметить выход за
   спецификацию в принципе, а организаторы прямо требуют, чтобы результат
   зависел от свойств сырья и задания качества.
   Это инженерное решение, а не победа метрики; оно записано здесь именно
   потому, что метрики выбор не решают.
3. **Выбор делается только на fit/valid**, уровень на test переоценивается на
   fit + valid — так же, как дообучается ridge (ADR-008). Закреплено тестом
   `test_test_split_never_participates_in_shrinkage_selection`.
4. **Порог допустимости действия** (ADR-010, §3) продолжает браться как
   backtest-RMSE на худшем горизонте, но теперь — у этого baseline.
   Правило «модель эффекта обязана выиграть у persistence» читается как
   «обязана выиграть у выбранного baseline»: сравнение с моделью, которую
   система не использует, ничего не защищает.

Выбранное значение: **shrinkage = 0.3, уровень 8.5 мг/кг (медиана fit),
на test уровень 8.6 мг/кг (медиана fit + valid)** — одинаково на всех четырёх
горизонтах.

## Проверка на test — один раз, после фиксации

```
 horizon_hours              model  shrinkage  level   n       rmse     mae   medae         r2
             0        persistence        NaN    NaN 253   2.620254 1.809881  1.2000  -0.132297
             0 shrunk_persistence        0.3    8.6 253   2.295533 1.529486  0.9000   0.130958
             0    ridge_telemetry        NaN    NaN 253 168.220604 25.41244  4.2195 -4665.9369
             1 shrunk_persistence        0.3    8.6 253   2.378757 1.552688  0.9400   0.066802
             2 shrunk_persistence        0.3    8.6 253   2.408764 1.561581  0.9300   0.043110
             3 shrunk_persistence        0.3    8.6 253   2.370787 1.548379  0.9500   0.073045
```

Сдвинутый baseline выигрывает у persistence (RMSE 2.296 против 2.620 при
h = 0) и у константы (2.483, замеряна в самооценке). Его R² положителен на
всех четырёх горизонтах — это первая модель проекта, которая на test лучше
константы. Прежний persistence остаётся в отчёте как эталон сравнения.

Что это число доказывает: ошибку прогноза на отложенной по времени истории.
Чего не доказывает: безопасность режима и эффект управляющего действия —
`evidence_type` у него по-прежнему `backtested`, а не «проверено на практике».

## Последствия

- Порог допустимости действия падает с 2.921 до **2.409 мг/кг** (худший
  горизонт, h = 2). Порог стал мягче не потому, что его подкрутили, а потому
  что прогноз стал точнее; правило осталось прежним.
- Прогноз агента качества больше не равен последнему анализу: при анализе
  8.4 мг/кг и уровне 8.6 прогноз равен 8.54. В выводе агента рядом с
  прогнозом печатается `last_published_sulfur_mg_kg`, чтобы оператор видел оба
  числа и не принимал одно за другое.
- Сценарий 1 (2026-02-04): прогноз 8.54 вместо 8.4, запас 1.46 мг/кг,
  риск по-прежнему `high`, вердикт `approved` для `hold` — вывод сценария не
  изменился, изменились числа под ним.
- `shrinkage = 0.3` означает, что 70 % прогноза — это исторический уровень.
  Систему это делает вялой к реальным броскам: при анализе 20 мг/кг прогноз
  будет 12.1, а не 20. Ограничение названо здесь и повторяется в карточке
  оператора; закрывать его должна модель, использующая сырьё и режим, а не
  подкрутка `shrinkage` под желаемую чувствительность.
