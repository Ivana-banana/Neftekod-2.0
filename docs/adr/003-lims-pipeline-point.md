# ADR-003: точка отбора `Pipeline` из формул ВАК не резолвится в LIMS

## Статус
Открыт — ожидает ответа организаторов.

## Контекст
Формулы листа «ВАК» ссылаются на `LIMS:24-2000.Pipeline.D15` и
`LIMS:24-2000.Pipeline.95%.T`. В `lims_export_2023.xlsx` такой точки отбора
нет — там представлены только точки установок «АВТ» и «Гидроочистка».
Неясно, `Pipeline` — это отдельная точка отбора, для которой данные не
выгружены в этом пакете, переименованная существующая точка, или
неактуальная/устаревшая ссылка в формуле.

## Решение
Ссылки на `Pipeline` не резолвятся текущими данными — любой расчёт,
зависящий от них, помечается как невыполнимый при текущем составе данных,
а не заменяется приближением (например, ближайшей по смыслу точкой АВТ).

## Последствия
Часть цепочки «ВАК» может быть недоступна для демонстрации, пока вопрос не
снят. Использование эрзац-точки вместо `Pipeline` без пометки допущения
нарушит принцип «явный отказ лучше рискованной догадки».
