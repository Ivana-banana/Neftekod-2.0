# ADR-001: тег `24-2000:Mg.Sulfur.Q` vs `24-2000:Mg.Sulfur`

## Статус
Частично закрыт ответом организаторов: подтверждены показатель серы, единицы и лабораторная точка; смысл суффикса `.Q` отдельно не объяснён.

## Уточнение 2026-09-10 — имеет приоритет над историей ниже

Источник: [ответы организаторов](../tz/organizer-clarifications.md).

ПАК `24-2000:Mg.Sulfur` соответствует `LIMS:Гидроочистка.2.Mg.Sulfur`,
продукт «Дизельное топливо». Единицы подтверждены ответом на вопрос о массовых
ppm (1 ppm = 1 мг/кг). Использовать фактическое имя из выгрузки;
автоматическое отождествление с `.Q` по-прежнему не подтверждено.

## История до получения ответа

## Контекст
Справочник «ПАК» (`docs/tz/tags_hackathon.md`) содержит тег `24-2000:Mg.Sulfur.Q`.
В реальном файле `pak_export_2023.xlsx` присутствует колонка
`24-2000:Mg.Sulfur` — без суффикса `.Q`. Неясно, это один и тот же
показатель (опечатка/расхождение версий справочника) или два разных
показателя (например, `.Q` — количество измерений, а не часть кода тега).

## Решение
Пока не подтверждено: код не должен молча отождествлять эти два тега.
Использовать `24-2000:Mg.Sulfur` из фактического файла как источник серы,
логировать несовпадение имени со справочником явно (не silently rename).

## Последствия
Если организаторы подтвердят, что это разные показатели — модуль загрузки
данных придётся переработать: серия серы может браться из не того столбца,
что напрямую влияет на жёсткую проверку «сера ≤ 10 мг/кг».
