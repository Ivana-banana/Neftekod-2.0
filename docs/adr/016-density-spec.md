# ADR-016: плотность при 15 °C как жёсткая проверка

## Статус

Принято 2026-09-15. Реализовано в `constraints.check_density`,
`spec.blend_density` и в цепочке ролей. Продолжает [ADR-015](015-spec-t95-cetane.md).

## Контекст

Разбор ГОСТ Р 52368 (`docs/research/2026-09-gost-r-52368-dt.md`, получен
2026-09-14) даёт полный перечень нормируемых показателей. Сверка перечня с
выгрузкой показала, что на точке товарного продукта `Гидроочистка.2` ЛИМС
измеряет **семь** нормируемых ГОСТ показателей, а проверялись три:

| Показатель | Тег | Норма ГОСТ (летний ряд, К5) | Проверялся до этой записи |
|---|---|---|---|
| Сера | `Mg.Sulfur` | ≤ 10 мг/кг | да |
| T95 | `95%.T` | ≤ 360 °C | да (ADR-015) |
| Цетановое число | `CetaneNumber` | ≥ 51,0 | да (ADR-015) |
| **Плотность при 15 °C** | `D15` | **820,0–845,0 кг/м³** | **нет** |
| Температура вспышки | `FlashPoint` | выше 55 °C | нет |
| Отгон при 250 °C | `I250` | < 65 % об. | нет |
| Отгон при 350 °C | `I350` | ≥ 85 % об. | нет |

Организаторы называли обязательными только первые три. Но остальные четыре —
не «дополнительные пожелания»: это нормы того же ГОСТ, и данные для них есть.
Не проверять их — незакрытая работа, а не отсутствие данных.

Плотность выбрана первой из четырёх по трём причинам, проверенным по выгрузке:

1. **Она нарушается на реальных данных.** 12 анализов продукта из 1015 выше
   845 кг/м³ (p99 = 846.1, max 856.2). Ниже 820 — ни одного.
2. **Оба компонента смешения измерены**, как у T95: продукт `Гидроочистка.2.D15`
   (1015 значений) и дешёвый компонент `Гидроочистка.1.D15` (123 значения).
   Для вспышки и `I250` компонент не измеряется вовсе, для `I350` — тоже нет.
3. **Есть документированная модель смешения** — аддитивность объёмов из ADR-004.

## Решение

### 1. Двусторонний диапазон

`config.DENSITY_MIN_KG_M3 = 820.0`, `config.DENSITY_MAX_KG_M3 = 845.0` по
ГОСТ Р 52368, табл. 2 (летний и межсезонный ряд; сорт подтверждён измеренным
CFPP — см. ADR-015, §1а). Это **первая проверка проекта, ограниченная с двух
сторон**: и слишком лёгкое, и слишком тяжёлое топливо вне спецификации.
Запас считается до ближайшей границы — запас до верхней ничего не говорит о
нижней. Направление закреплено тестами с обеих сторон.

Как и остальные показатели спецификации, плотность проверяется безусловно:
отсутствующее значение — нарушение.

### 2. Модель смешения — аддитивность объёмов

`1/ρ_blend = Σ wᵢ/ρᵢ` (ADR-004: «плотность — аддитивность объёмов», не линейное
усреднение). Массовые доли делятся на плотности компонентов, то есть
складываются удельные объёмы. Источник прямо разрешает пренебречь небольшим
сжатием объёма при смешении. Модель историей не проверялась, поэтому у
кандидатов остаётся `evidence_type: simulated_unvalidated`.

### 3. Порог устаревания 48 ч, и его цена измерена

Отбор `D15` продукта суточный (p90 интервала на train — 1.02 суток), поэтому
порог тот же, что у серы и T95: **48 ч** — по аргументу ADR-010, §2 (суточный
отбор плюс публикация 4 ч, значит пропущена хотя бы одна проба). У дешёвого
компонента отбор заметно реже (p90 интервала 79.3 суток), порог — **80 суток**
по правилу p90 из ADR-013.

**Измеренное последствие, которое нельзя замолчать.** Плотность публикуется
хуже серы. На сетке из 5089 часовых моментов test-периода доля моментов, где
последний анализ старше 48 ч:

| Показатель | медиана возраста | доля > 48 ч |
|---|---|---|
| Сера продукта | 16 ч | 11.6 % |
| T95 продукта | 17 ч | 12.1 % |
| **Плотность продукта** | 23 ч | **29.2 %** |

То есть примерно в трети моментов плотность не подтверждена, и рекомендация не
выдаётся по этой причине. Порог при этом **не** ослаблен: снижать требование к
свежести потому, что оно неудобно, — ровно та подгонка, которую запрещает
`CLAUDE.md`. Число приведено здесь, чтобы решение принималось с открытыми
глазами, а не обнаружилось на демонстрации.

Частный случай: на момент выдачи сценария 1 (2026-02-04 12:00) последний
анализ плотности старше 48 ч — ему 50.0 ч, тогда как сере там 26 ч.
**Проверено прогоном 2026-09-15**: сценарий 1 стал отказом, и плотность —
его единственная причина (`hold`: S = 9.298 мг/кг, T95 = 345.0, ЦЧ = 52.9 —
все в пределах, `density: None`). В сценарии 4 плотность добавилась второй
причиной к нарушению T95. Что с этим делать — [ADR-017](017-unverified-vs-violated.md).

### 4. Плотность ограничивает состояние продукта, но не является рычагом

Доля дешёвого компонента ограничена балансом серы величиной порядка 1e-4
(ADR-013), поэтому даже компонент на 15–25 кг/м³ плотнее сдвигает плотность
смеси на сотые доли кг/м³ — ниже разрешения лабораторного значения. Закреплено
тестом `test_blending_lever_cannot_move_density_because_sulfur_caps_the_fraction`.

Практический смысл: связывающий случай — не «действие вывело плотность за
предел», а «измеренная плотность продукта уже вне диапазона». Тогда недопустим
и `hold`: система не подтверждает соответствие, которого нет.

### 5. Оркестратор пересчитывает плотность сам

`blend_density_recomputed` вызывает модель смешения заново на компонентах
входа; `density_min_kg_m3_unchanged` и `density_max_kg_m3_unchanged` не дают
раздвинуть диапазон ни с одной стороны. Закрыто adversarial-тестами.

## Последствия

- Показателей спецификации в жёсткой проверке стало четыре: сера, T95,
  цетановое число, плотность. Запас по одному не покупает нарушение по другому.
- `pytest -q` — 271 passed, 9 skipped (было 241).
- Три оставшихся нормируемых показателя, измеряемых на той же точке, **не
  реализованы**: температура вспышки (> 55 °C; на выгрузке p01 = 48.2 °C, то
  есть нарушается), отгон при 250 °C (< 65 % об.; max по выгрузке 54, то есть
  не связывает) и отгон при 350 °C (≥ 85 % об.; в теге есть нефизичные 0 и 350,
  требуется отдельная отбраковка). Для всех трёх дешёвый компонент не измеряется,
  поэтому модели смешения нет и проверять их можно только как состояние
  продукта, а не как эффект действия. Это следующая работа, а не забытый случай.
- Цетановый индекс (ГОСТ требует ≥ 46 наравне с цетановым числом) по-прежнему
  не считается: для расчёта по ISO 4264 нужна точка `T10` разгонки, а в ЛИМС
  есть только IBP, 50 %, 90 %, 95 % и конец кипения. Это отсутствие данных, а
  не пропуск.
