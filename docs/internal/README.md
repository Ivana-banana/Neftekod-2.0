# Рабочая история команды

Файлы в этом каталоге — планы по дням, промпты сессий Claude Code, самооценка
и бриф для deep research. Они сохранены как история принятия решений и **не
нужны для запуска или проверки решения**. Числа в них (число тестов, метрики)
могли устареть; актуальные — в корневом `README.md` и `docs/adr/`.
